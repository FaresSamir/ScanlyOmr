=== مصحح البابل شيت مع السكانر ===

متطلبات:
- Python 3.8+
- Windows فقط للسكانر (TWAIN)

تشغيل:
  دبل كليك على "تشغيل.bat"

أو يدوياً:
  pip install opencv-python numpy Pillow pytwain
  python omr_grader.py

ملاحظة السكانر:
- TWAIN يشتغل على ويندوز فقط
- تأكد إن درايفر السكانر متثبت
- DPI المنصوح: 300
